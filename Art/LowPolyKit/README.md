# 이름 없는 도시 · 로우폴리 모델링 키트 v5

모델링 에셋 초안입니다. 게임 코드·빌드·렌더러·NPC 상태 구조에는 적용하지 않았습니다.

NPC 리깅, 몹 7종 및 110개 키프레임 동작을 추가했습니다. v5에서 골반 가중치와 팔 비율/팔꿈치 토폴로지, 2족 달리기, 4족 걷기·트로트·갤럽을 수정했습니다. 애니메이션 원본은 `Characters_Rigged.blend`, 스킨/애니메이션 GLB는 `rigged/`에 있습니다. 자세한 목록과 적용 기준은 [ANIMATION_README.md](ANIMATION_README.md)를 참조하십시오. 아래 내용의 `meshes/`와 `LowPolyKit.blend`는 기존 정적 에셋 세트에 해당합니다.

몬스터는 사용자 제공 컨셉 보드를 기준으로 종이상자 요괴·역무원 요괴·붉은 뿔 요괴·보안 병기(인간형 4종), 철문 견마·혼종체·공허 추적자(4족 3종)로 교체했습니다. 이전 몹의 활성 GLB·메시·골격·클립은 제거했습니다.

## 결과물

- `LowPolyKit.blend`: 공용 원점의 원본 메시 라이브러리와 조합 확인용 링크 인스턴스.
- `meshes/*.glb`: 이름이 지정된 개별 메시 63개. 각 파일은 독립적으로 가져올 수 있습니다.
- `previews/npc_lineup.png`: 기존 이름 있는 주민 11명 조합 시안.
- `previews/environment_catalog.png`: 수정된 상업지구 건물 3종.
- `previews/buildings_01_Commercial.png`부터 `buildings_07_Origin.png`: 지역별 건물·시설 3종씩, 7개 이미지.
- `previews/building_overview.png`: 건물·시설 21종 전체 배치.
- `previews/nature_catalog.png`: 구조물·자연물 기존 18종.
- `data/building_regions.json`: 지역과 건물 인덱스의 대응표.
- `data/mesh_catalog.json`: 슬롯별 고정 인덱스, 메시 이름, 경로, 삼각형 수.
- `data/npc_appearance_presets.json`: NPC별 파츠 인덱스. 데이터 제안이며 게임에 연결되지 않았습니다.
- `data/palette.json`: 기본 재질과 향후 색상 교체 제안.
- `data/asset_validation.json`: 에셋 구조 검사 결과.

## 분위기와 형태

건물 v2의 시각 기준은 `2026GSE01/doc/로우 폴리 도시 건물 컨셉 보드.png`입니다. 현대 다층 건축에 전통 기와지붕과 이질적인 요괴/기억 요소가 혼합되는 방향을 적용했습니다. 창틀·돌출 간판·옥상 설비·배관·실외기·난간·지붕 기와는 메시 형상으로 표현했습니다. 상업지구는 황토색과 청록색, 관리국은 차가운 회색, 병원은 백색과 적색, 교단은 적갈색 기둥과 기와, 원점은 분리된 기둥과 청록/보라색으로 구분합니다. 간판의 영문은 형태 확인용 임시 표시이며 최종 세계관 문구는 아닙니다. NPC는 v1을 유지하며 궁수는 사냥꾼, 갑옷은 경비 방호 장비로 해석했습니다.

컨셉 보드 전체의 모든 소품/건물 수십 종을 복제한 결과물이 아니라, 7개 지역에서 각각 대표 3종을 선정해 실제 입체 메시로 제작한 21종 세트입니다. 작은 표면 그림이나 질감은 텍스처로 복사하지 않았습니다.

캐릭터는 머리 0.6m, 전체 약 1.8m의 3등신입니다. 머리카락과 소품 끝은 이 높이를 조금 넘을 수 있습니다. 평평한 면과 거친 실루엣을 유지하고 모든 내보내기 메시를 삼각형으로 확정했습니다. 재질은 단색이며 외부 텍스처 의존성이 없습니다.

## NPC 조합 규칙

| 슬롯 | 수량 | 구성 |
| --- | ---: | --- |
| body | 2 | 남/여 기본 얼굴·목·손 |
| hair | 4 | 짧은 머리·긴 머리·크롭·묶은 머리 |
| top | 5 | 주민·갑옷·궁수·기록자·순례자 |
| legs | 3 | 바지·방호 바지·천 감은 바지 |
| feet | 2 | 부츠·신발 |
| accessory | 5 | 목도리·가방·화살통·배지·염주 |
| prop | 3 | 활·창·기록장 |

몸통과 다리의 피부 메시를 생략하고 의복이 해당 형태를 담당합니다. 남녀 파츠의 외곽 치수를 공유하여 성별마다 갑옷·옷을 복제하지 않습니다. body/hair/top/legs/feet는 각 1개가 필수이며 accessory/prop은 `-1`로 생략할 수 있습니다. 성별에 따른 장비 제한은 없습니다. 긴 머리는 등 뒤를 차지하므로 화살통과 겹칠 수 있습니다. 제공 시안은 긴 머리+화살통 조합을 사용하지 않습니다. 향후 구현에서 이 조합을 제한하거나 헤어 숨김 정책을 추가해야 합니다.

인덱스는 각 슬롯 안에서 0부터 시작하고 슬롯 간에 공유하지 않습니다. 기존 인덱스의 의미를 바꾸거나 재정렬하지 말고 새 파츠를 끝에 추가하십시오. `schema_version`은 1입니다. NPC 조합은 메시를 복제하는 설계가 아니라 동일 메시 참조를 재사용하는 설계입니다. 실제 공유·배칭·색상 변경은 적용 작업에서 구현해야 합니다.

현재 게임 문서/소스에 존재하는 도윤·유리·건우·갈치·붉은 눈·미령·덕수·이안·무명 순례자·초소장·백연의 시안을 포함했습니다. 성별과 외모는 확정된 설정이 없어 제안값입니다. `appearance_id`는 아트 프리셋 ID이며 런타임 NPC ID가 아닙니다. 추가 마을의 동적 주민은 적용 작업에서 각 NPC에 프리셋 또는 슬롯 인덱스를 저장해야 합니다. 본 작업은 그 상태 구조를 변경하지 않습니다.

## 좌표·조립·이름

- Blender: 미터, Z 위, -Y 정면. NPC 발바닥 중앙 `(0,0,0)`.
- GLB: 표준 glTF 변환으로 Y 위, +Z 정면. 재가져오기 도구의 축 변환을 중복 적용하지 마십시오.
- 모든 NPC 파츠는 같은 원점을 사용합니다. 각 파츠를 바운딩 박스 중심으로 재정렬하지 않고 동일 변환에 놓으면 조립됩니다.
- 건물과 자연물도 지면 기준 원점을 사용합니다. 벽/문은 X축 방향으로 이어집니다.
- 이름: `SM_NPC_<Slot>_<Index>_<Variant>` / `SM_ENV_<Type>_<Index>_<Variant>`.
- 재질 이름: `MAT_<color>`; `MAT_memory`는 청록색 표시 재질이며 자체 발광 효과는 아직 없습니다.
- Blender의 `01_MESH_LIBRARY`는 렌더와 뷰포트에서 숨겨진 원본 모음입니다. 원본 편집 시 컬렉션 표시를 켜십시오. `02`, `03`, `04` 컬렉션은 같은 메시 데이터를 참조한 프리뷰입니다. 건물 03은 7행×3열로 지역별 배치합니다.

## 재생성과 검증

`source/author_assets.py`는 Blender에서 모델링과 파일 내보내기에만 쓰는 제작 레시피입니다. 게임 코드가 아니며 실행 시 이 키트의 에셋 파일을 다시 생성합니다. 원본을 수동 수정한 뒤 실행하면 수정본을 덮어쓰므로 먼저 별도로 보관하십시오.

v2 재생성 순서: `author_assets.py`로 기본 키트를 생성한 다음 `author_city_buildings.py`로 컨셉 보드 건물 패스를 적용합니다. 현재 수정 전 v1 원본과 메시 카탈로그는 `revisions/v1/`에 보관했습니다. v2만 다시 실행해도 건물 패스를 재생성할 수 있습니다.

검증은 내보내기 파일 존재·빈 메시·유한 좌표·삼각형·프리셋 인덱스 참조를 검사합니다. 렌더 프리뷰는 형상과 배색 검토용이며 실제 게임 렌더러에서의 표시나 애니메이션 호환성을 보증하지 않습니다.
