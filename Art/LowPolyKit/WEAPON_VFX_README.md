# 요괴병기 공격 VFX

`Weapon_VFX.blend`는 별도 VFX 제작 원본입니다. 게임 코드와 기존 모델/애니메이션 파일은 수정하지 않았습니다. 무기 모델 계열 인덱스는 `data/yokai_weapon_catalog.json`과 같습니다.

| 계열 | 일반 공격 | 스킬 효과 |
| --- | --- | --- |
| 0 묵 | 푸른 초승달 참격 | 월영 원형 참격 |
| 1 영혼총 | 총구 섬광·직선 탄도 | 5방향 혼령 산탄 |
| 2 클로 | 보라색 3줄 발톱 궤적 | 시간차 3회 발톱 궤적 |
| 3 소령 | 좌우 총구 섬광·쌍 탄도 | 좌우 부채꼴 연속광 |
| 4 메스 | 청록 교차 베기 | 가위 교차·닫힘 충격광 |
| 공통 | 명중 섬광·파편 | 재사용 가능한 피격 효과 |

총 11개입니다. 소령·메스 스킬은 현재 문서에서 확정된 전투 규칙이 아닌 시각 효과 초안이며 피해/판정은 포함하지 않습니다. 영혼총의 탄도는 짧은 시각 표현입니다. 실제 충돌 발사체는 적용 작업에서 따로 연결해야 합니다.

각 효과는 `vfx/{이름}.glb`의 메시·노드 변환 키프레임과 `vfx/{이름}_atlas.png`의 투명 RGBA 플립북을 함께 제공합니다. GLB와 플립북은 같은 효과의 대체 표현입니다. 원본 메시 이름은 효과명과 Blade/Core/Muzzle/Tracer/Spark 등 역할을 포함합니다. 소재는 발광색을 포함하며 런타임 후광은 엔진 블룸 설정에 따라 달라집니다. GLB는 스케일·위치 애니메이션만 사용하며 색/투명도 셰이더 애니메이션은 필요하지 않습니다.

플립북 셀은 256×256, 4열, 왼쪽→오른쪽 다음 행 순서입니다. 일반/명중 효과는 16프레임(4×4), 스킬은 24프레임(4×6), 재생속도는 30fps입니다. 알파 배경을 보존했습니다. 어두운 배경에서 additive 합성을 권장하며 일반 알파 합성도 가능합니다. 미리보기 GIF는 보기 편하게 어두운 배경을 합성한 것으로 게임용 투명 원본은 PNG입니다. 이미지 가장자리에는 여백을 두었으며 텍스처 적용 시 clamp와 셀별 UV 보간 경계를 고려해야 합니다.

`data/weapon_vfx_catalog.json`의 `index`, `family_index`, `kind`로 선택하고 `frames`, `fps`, `events`로 재생합니다. 시각 발생 시점은 2프레임이며 삼연 발톱은 2·6·10프레임에 차례로 등장합니다. 이는 이 아트 클립의 타이밍이며 게임 스킬의 준비 시간·피해 간격·쿨다운을 대체하지 않습니다. 진화 단계별 색이나 크기 변경은 적용 쪽에서 선택할 수 있으며 이번 패키지는 계열별 공통 공격 효과입니다.

효과는 로컬 Blender XY 평면(법선 +Z), GLB XZ 평면(법선 +Y)을 사용합니다. 부착 지점은 검/클로/가위의 공격 평면 중심, 총기의 총구 소켓, 공통 명중 효과의 충돌 지점입니다. 총기 효과는 로컬 XY 평면에서 -Y 쪽 총구로부터 +Y 쪽 탄도 방향을 바라보도록 그렸습니다. 월드 배치 시 공격 평면과 총구 방향에 맞춰 회전·위치를 정렬해야 합니다. 소령 효과는 좌우 발사점을 포함한 한 묶음이며 실제 양손 총구에 각각 연결하려면 해당 Muzzle/Tracer 노드를 분리해 사용합니다.

Blender 원본은 `FX_번호_효과명` 컬렉션별로 정리되어 있습니다. 기본적으로 첫 효과만 표시되므로 다른 효과를 볼 때 해당 컬렉션의 오브젝트 숨김과 렌더 숨김을 해제하고 나머지를 숨깁니다. GLB는 각 파일에 효과명과 같은 애니메이션 클립 하나를 포함합니다.

재생성: Blender background로 `source/author_weapon_vfx.py`, 이어서 Python으로 `source/package_weapon_vfx.py` 실행. `data/weapon_vfx_validation.json`에서 GLB 노드·애니메이션·유한 경계값과 투명 프레임을 검증합니다.
