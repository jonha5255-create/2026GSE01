# 계약 요괴와 요괴병기 모델링

파지 revision 2는 묵의 손잡이 중앙, 영혼총의 방아쇠 손잡이와 앞손잡이, 클로의 열린 손목 커프에 손을 맞춥니다. 소령은 좌우 권총 손잡이, 메스는 쌍검으로 분리했을 때 좌우 손잡이 고리의 중심을 각각 사용합니다. `data/yokai_weapon_catalog.json`의 소켓은 Blender 로컬 좌표입니다. 각 파지 자세는 `Characters_Rigged.blend`의 기존 검·쌍권총·클로·가위 공격 클립에 들어 있습니다. `previews/yokai_weapon_grips.png`는 이 클립의 준비·공격 자세를 비교한 렌더입니다.

게임 코드는 수정하지 않은 별도 모델링 패키지입니다. `Yokai_Weapons.blend`가 원본이며 `yokai/`의 GLB와 `data/yokai_weapon_catalog.json`으로 전달합니다. 기존 NPC·몬스터·건물 파일은 유지합니다.

| family_index | 계열 | 동행 형태 | 무기 형태 |
| --- | --- | --- | --- |
| 0 | 묵 | 뿔 달린 기억 가면 | 갑각 도검 |
| 1 | 영혼총 | 외눈 등딱지 요괴 | 개머리판·손잡이·탄창·노출 총열을 가진 양손 영혼총 |
| 2 | 클로 | 꼬리를 가진 고양잇과 포식자 | 3지 클로 건틀릿 |
| 3 | 소령 | 역무원 모자와 철도 등롱 | 좌우 쌍권총 |
| 4 | 메스 | 갈라진 의료 가면과 사마귀 앞발 | 분리 가능한 가위/쌍검 |

0·3·4는 스토리 명세의 묵·소령·메스입니다. 1·2는 현재 플레이 문서의 원거리·클로 계열이며 고유 이름은 아직 지정하지 않았습니다. 문서에 외형이 확정되지 않은 부분은 이번 모델링 초안의 디자인입니다.

각 계열은 동행/무기 2형태, 레벨 1·3·6·9에 해당하는 진화 E00~E03을 제공합니다. 총 40개 조립 GLB이지만 원본은 기본 P00와 추가 파츠 P01~P03을 공유하는 40개 모듈 그룹입니다. E02는 P00+P01+P02를 사용합니다. 진화 GLB를 매번 함께 로딩하기보다 카탈로그의 파츠 인덱스로 필요한 조합을 선택할 수 있습니다. 좌우 무기는 같은 모듈 안에서 별도 메시 노드입니다.

이름 규칙: `SM_YK_{계열번호}_{계열명}_{Companion|Weapon}_P{파츠번호}`. 소령/메스 무기의 `_L`, `_R`은 독립 부착 노드입니다. 선택 정보는 `family_index`, `form_index`(0 동행/1 무기), `evolution`(0~3), `part_indices`로 전달합니다. 기존 NPC 파츠 인덱스와는 별도 네임스페이스입니다.

단위는 미터입니다. Blender 동행 전방은 -Y, 위는 +Z이고 GLB 동행 전방은 +Z, 위는 +Y입니다. 무기는 손잡이 원점을 기준으로 길이 방향을 Blender +Z(GLB +Y)로 제작했으므로 손 본 부착 시 회전 정렬이 필요합니다. 소령 좌우 손잡이, 총구, 영혼총 보조 손 위치, 메스 가위 회전축은 카탈로그 `sockets`에 Blender 좌표로 기록했습니다. 소켓은 메타데이터이며 엔진의 부착 기능은 구현하지 않았습니다.

둥근 저폴리 실루엣, 모서리 베벨, 보간 노멀과 재질 색을 사용합니다. GLB의 NORMAL을 유지해야 현재 미리보기와 같은 표면이 나옵니다. 텍스처 의존성은 없습니다. 동행/무기는 형태와 소재를 공유하지만 같은 토폴로지의 모프 타깃은 아닙니다. 이번 패키지에는 새 리그·키프레임·변신 애니메이션을 포함하지 않습니다.

`previews/yokai_weapon_lineup.png`는 각 행이 한 계열이며 왼쪽부터 기본 동행·기본 무기·최종 동행·최종 무기입니다. `data/yokai_weapon_validation.json`에는 실제 GLB 노드 구성·정점 수·삼각형 수·노멀 및 경계값 검증 결과가 있습니다.

재생성 순서: Blender에서 `source/author_yokai_weapons.py`, 이어서 `source/finalize_yokai_weapons.py`를 background 실행한 후 Python으로 `source/validate_yokai_weapons.py`를 실행합니다.
