# 일반 폐허의 부유 건물 배치 수정

2026-11-04

첨부 화면의 분리된 상층부는 `SM_ENV_Building_16_FloatingBuilding`의 원래 모델 구조입니다. 기존 배치 코드가 일반 폐허에 15·16·17번 모델을 무작위로 선택하면서 부유 콘셉트 건물이 평범한 외곽 도로변에도 반복 배치됐습니다. 아트 원본의 [설명](../Art/LowPolyKit/README.md)과 [왜곡 지역 미리보기](../Art/LowPolyKit/previews/buildings_06_Distortion.png)에서도 같은 분리 형태를 확인했습니다.

일반 폐허는 지면에 연결된 15번 파손 건물과 17번 기울어진 상가를 사용하도록 수정했습니다. 시드의 별도 비트로 0도·90도 방향을 선택해 같은 방향으로 반복되는 배치도 줄였습니다. 마을의 무작위 건물 후보에서도 `Floating` 모델을 제외합니다. 원본 콘셉트 에셋은 보존하며, 추후 부유 랜드마크가 필요하면 별도 배치 규칙으로 연결할 수 있습니다.

폐허가 플레이어를 가리면 기존 마을 건물처럼 투명도를 낮추도록 적용했습니다. 필지·충돌 판정·도로 연결·미니맵 기준 데이터는 그대로 사용합니다.

검증:

- x64 Release / Debug 빌드 통과.
- 게임·장면·렌더러 검사 235 PASS / 0 FAIL.
- 7개 지역 테마 × 512개 선택 값에서 부유 모델이 일반 건물과 폐허 후보에 들어가지 않는지 검사.
- 마을·원정 구역·도로 교차로·외곽 폐허의 실제 캡처와 OpenGL 오류 검사 통과.

`--smoke-test --seed=2026 --no-monitor`로 재검사합니다. 새 외곽 검증 화면은 실행 파일 옆 `living-world-grounded-ruins.bmp`에 저장됩니다. 배치 제외 내역은 JSONL의 `world_art_placement_excluded` 이벤트에 기록합니다.
