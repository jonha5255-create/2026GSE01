# 1. 게임 핵심 개요

## 1.1 한 줄 소개

공간이 뒤틀리고 사람과 장소의 이름이 사라지는 현대 도시에서, 주인공이 요괴와 계약하여 요괴병기를 사용하고 사라진 여동생의 흔적과 공간 왜곡의 원점에 접근하는 2.5D 액션 RPG.

## 1.2 핵심 스토리 목표

1. 사라진 여동생 `윤하린`의 흔적을 찾는다.
2. 첫 요괴 `묵`과 계약한다.
3. 공간 왜곡과 기억 삭제의 관계를 조사한다.
4. 기억관리국, 융합교단 등 주요 세력의 목적을 확인한다.
5. 새로운 요괴와 계약하고 요괴병기를 확장한다.
6. 영구 융합의 대가를 경험한다.
7. 최초 왜곡 지점 `원점`에 도달한다.
8. 하린과 묵의 진실을 확인한다.
9. 최종 선택으로 엔딩을 결정한다.

## 4.1 진엔딩 권장 조건

```cpp
bool CanUnlockTrueEnding(const StoryFlags& flags)
{
    return
        flags.mukPersonalityPreserved &&
        flags.sparedSoryeong &&
        flags.sparedMes &&
        flags.minimizedYokaiKills &&
        flags.recorderMemoryQuestComplete &&
        flags.yokaiRelationshipQuestsComplete &&
        flags.mukSync >= 80;
}
```

# 11. 영구 융합 시스템

```cpp
struct FusionRequest
{
    YokaiID primary;
    YokaiID secondary;

    int primarySync;
    int secondarySync;

    int relationship;
    DistortionLevel distortion;

    bool bothConsent;
};
```

## 융합 가능 조건

```cpp
bool CanPermanentFuse(const FusionRequest& request)
{
    return
        request.bothConsent &&
        request.primarySync >= 60 &&
        request.secondarySync >= 60 &&
        request.relationship >= 50;
}
```

## 주의

영구 융합 후 원래 형태 복원 불가.

묵의 인격 보존 여부는 진엔딩 조건에 영향을 준다.

## Boss Update 예시

```cpp
void UpdateBoss(BossData& boss)
{
    float hpRatio =
        static_cast<float>(boss.hp) /
        static_cast<float>(boss.maxHP);

    if (hpRatio <= 0.75f && boss.phase == 1)
    {
        boss.phase = 2;
        boss.state = BossState::Phase2;
    }

    if (hpRatio <= 0.40f && boss.phase == 2)
    {
        boss.phase = 3;
        boss.state = BossState::Phase3;
    }

    if (boss.hp <= 0)
    {
        boss.state = BossState::Defeated;
    }
}
```

# 24. 개발 시 핵심 원칙

1. **스토리 진행과 맵 진행을 분리한다.**
   - MapManager는 장소를 관리한다.
   - QuestSystem은 목표를 관리한다.
   - StoryFlags는 플레이어 선택과 중요한 사건을 저장한다.

2. **보스 AI와 스토리 이벤트를 분리한다.**
   - BossAI가 직접 다음 맵을 열지 않는다.
   - 보스 사망 이벤트를 QuestSystem/EventSystem이 받아 처리한다.

3. **요괴 데이터와 무기 데이터를 분리한다.**
   - 요괴는 인격/관계/기억을 가진다.
   - 병기는 전투 능력을 가진다.

4. **엔딩 조건은 마지막 선택 하나만으로 결정하지 않는다.**
   - 이전 계약
   - 요괴 생존
   - 동조율
   - 관계 퀘스트
   - 융합 선택
   을 함께 검사한다.

5. **맵마다 새로운 시스템을 하나씩 소개한다.**

```text
MAP 01 → 기본 전투 / 묵
MAP 02 → 계약 선택 / 원거리 병기
MAP 03 → 인간 결투 / 스킬 봉인
MAP 04 → 환경 기믹 / 메스
MAP 05 → 영구 융합
MAP 06 → 플레이 기록 반영 보스
MAP 07 → 모든 시스템 종합
```
