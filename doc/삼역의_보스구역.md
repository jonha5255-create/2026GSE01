# 삼역의 보스 구역

시작 마을 주변 평지에 고정된 세 구역을 추가합니다. 모든 구역 중앙은 청크 내부 (320,320)이며 중앙 전투 공간에 겹치는 건물을 제거하고 기존 연결 도로는 유지합니다.

외곽 폐허에서는 마을 간 간선도로(arterial)는 지면에 표시하고, 내부 잔도로·사각 앞마당은 표시하지 않습니다. 나머지 지면은 불규칙한 흙과 이끼색 얼룩, 균열, 작은 석편으로 구성합니다. 마을 내부 도로와 보스 구역 문양은 유지하며 지면 캐시 키는 v9입니다.

미니맵도 같은 도로 표시 규칙을 사용합니다. 마을/폐허 바탕색, 건물/잔해/성벽, 세 보스 구역을 구분하며 중간 보스는 큰 금색 점으로 표시합니다. M을 누르면 플레이어 중심의 확대 지도로 전환하고 다시 누르면 원래 미니맵으로 돌아갑니다. 확대 상태에서는 마우스 공격/스킬 입력을 차단하지만 월드 시뮬레이션은 계속 진행됩니다. 지도는 현재 로딩된 청크를 표시하며 전체 탐험 기록을 저장하는 지도는 아닙니다.

| 청크 | 배경 | 보스 | 전용 퀘스트 아이템 |
| --- | --- | --- | --- |
| (2,0) | 핏빛 제단: 붉은 흙과 제단 문양 | 뿔왕, 체력 420 | 핏빛 인장 |
| (0,2) | 독안개 분지: 녹색 오염 지면 | 포식견, 체력 510 | 독안개 심장 |
| (-2,0) | 붕괴 석정: 청회색 지면과 석편 문양 | 거신, 체력 600 | 석정 핵 |

기존 세 몬스터 모델과 공격 유형을 활용한 서로 다른 보스 Actor입니다. 기존 일반 몬스터와 다른 지역 중간 보스도 유지합니다. 배경은 캐싱된 FloorActor 메시에 포함됩니다. 독안개 지면은 시각 테마이며 독 피해나 안개 시뮬레이션은 없습니다.

별도 퀘스트 '삼역의 유물'은 시작부터 활성화됩니다. 왼쪽 패널에 수집 수, 다음 구역 청크 좌표와 거리를 표시합니다. 플레이어가 보스를 처치하면 아이템을 즉시 퀘스트 소지품으로 자동 획득합니다(바닥에 떨어지는 별도 줍기 오브젝트는 아님). NPC가 대신 처치한 경우 지급하지 않습니다. 세 아이템을 모두 모으면 150전과 캐릭터 경험치 120을 한 번 지급합니다.

청크 재생성/보스 재처치로 아이템 및 완료 보상을 중복 지급하지 않습니다. 일반 보스 보상과 재생성 규칙은 유지됩니다. 수집 상태는 현재 세션에만 보존되며 R/게임 종료 시 초기화됩니다. 기존 하린 메인 퀘스트에는 영향을 주지 않습니다.
