# 요괴 독립 성장과 스킬

## 플레이 방법

1/2/3으로 검·원거리·클로 요괴를 선택합니다. 각 요괴는 별도 레벨과 경험치를 가집니다. 전환 시 동행 상태로 바뀌며 Q로 무기화한 후 마우스 우클릭으로 전용 스킬을 사용합니다. K 키는 더 이상 스킬을 실행하지 않습니다. 화면 상단에 현재 요괴 레벨·경험치·스킬 이름·해금 조건·재사용 대기시간이 표시됩니다.

몬스터 처치 시 현재 선택한 요괴에 일반 14, 중간 보스 80 경험치를 지급합니다. 파밍 모드 보스도 80입니다. 캐릭터 경험치와 별도 처리되므로 캐릭터 만렙에서도 요괴는 성장합니다. 퀘스트 보상과 영혼석은 기존 캐릭터 경험치 규칙을 유지합니다. 발사체 발사 후 요괴를 바꾸면 처치 시점에 선택한 요괴가 경험치를 받습니다.

필요 경험치는 `30 + 현재 요괴 레벨 × 20`, 최대 레벨은 10입니다. 미선택 요괴의 성장 상태는 유지됩니다. 요괴 레벨마다 기본 공격 피해가 2씩 추가됩니다. 캐릭터 레벨의 체력·성장 보너스는 기존 규칙을 유지합니다.

## 진화

레벨 3·6·9에 진화 단계가 올라갑니다. 공통 결정 날개와 회전 장식 대신, 요괴의 신체 특징이 무기 구조로 이어지도록 구성합니다. 검은 푸른색, 원거리는 금색, 클로는 보라색 영혼핵과 어두운 갑각, 상아색 뿔/날을 공유합니다. 성장 시 레벨업 효과와 해금/진화 안내를 표시합니다.

| 계열 | 동행 요괴의 성장 | 무기화 시 대응 |
| --- | --- | --- |
| 검 | 뿔 달린 가면 → 어깨 갑각 → 측면 골편 → 이마 결정 | 가느다란 검 → 넓은 갑각 칼날과 뿔 가드 → 측면 돌기 → 칼날 결정 |
| 원거리 | 외눈 등딱지 요괴 → 분절 갑각 → 옆뿔 → 쌍 영혼선 | 기본 영혼포 → 분절 약실과 핵 → 뿔 형태 후방 외장 → 발광 레일과 총구 |
| 클로 | 꼬리와 앞발을 가진 포식자 → 발 갑각 → 겹골편 → 발 영혼핵 | 기본 3지 클로 → 갑각 건틀릿 → 겹골편과 깊어진 갈고리 날 → 발 영혼핵이 건틀릿 핵으로 연결 |

동행 형태와 무기 형태 모두 같은 선택 요괴의 `Evolution()` 단계를 사용합니다. 기존 공격 모션과 판정 거리는 유지하며 외형 성장 자체가 사거리를 바꾸지는 않습니다. 자동 렌더링 검증은 세 계열 × 네 레벨 × 동행/무기의 24개 비교 캡처를 생성합니다.

## 스킬

세 요괴 모두 레벨 3에 고유 액티브 스킬 하나가 열립니다. 레벨 6·9에는 외형 진화와 레벨에 따른 피해 증가가 적용되며 추가 스킬 슬롯이 열리지는 않습니다.

| 요괴 | 스킬 | 효과 | 재사용 |
| --- | --- | --- | --- |
| 검 | 월영 참격 | 반경 145 안 몬스터 광역 타격 | 8초 |
| 원거리 | 혼령 산탄 | 실제 충돌 발사체 5발을 부채꼴로 발사 | 8초 |
| 클로 | 삼연 발톱 | 전방 반경 100 안 몬스터를 0.14초 간격으로 3회 타격 | 6초 |

검·원거리 스킬의 타격당 피해는 `32 + 요괴 레벨 × 3`, 클로는 `13 + 요괴 레벨 × 3`입니다. 0.25초 준비 후 판정이 시작됩니다. 스킬은 몬스터만 대상으로 하며 벽 너머 대상을 맞히지 않습니다. 원거리는 발사체가 이동하며 충돌하므로 실제 명중 수에 따라 피해가 달라집니다.

준비 중 수축·확장하는 에너지 고리, 검의 원형 참격, 원거리 총구 발광과 산탄, 클로의 연속 교차 잔상을 렌더링합니다. 근접 스킬은 기존 무기 휘두르기 모션도 연동합니다. 무기 해제·요괴 전환·사망 시 시전을 취소하며, 요괴별 재사용 대기시간은 유지되어 전환으로 초기화되지 않습니다.

## 기술 및 검증

### 원거리 총기 외형과 반동

원거리 무기는 개머리판, 총몸, 손잡이, 탄창, 노출 총열과 가늠쇠를 가지며 양손으로 받칩니다. 진화 갑각은 총몸 위에 결합되므로 기본 총기 실루엣이 유지됩니다.
일반 발사 성공 시 0.16초, 산탄 스킬 발사 시 0.24초 동안 이동 입력을 멈춥니다. 조준 방향 반대로 감쇠하는 반동을 주며 일반 사격은 최대 약 7.1, 산탄은 약 11.4 월드 단위만큼 이동합니다. 벽에 막히면 실제 이동량은 줄어듭니다. 총 자체도 뒤로 당겨지고 살짝 들리는 시각 반동을 표시합니다.
자동 사격과 왼쪽 클릭 사격은 같은 성공 경로를 사용합니다. 표적이 없거나 쿨타임으로 실패한 발사는 반동을 만들지 않습니다. 반동은 다음 플레이어 업데이트에서 기존 월드 충돌 이동 함수로 처리되며 사망/승리 시 해제됩니다. 자동 사격이 계속되는 동안에는 발사마다 짧은 정지가 반복됩니다.

성장 상태는 PlayerActor의 요괴별 배열, 스킬 시전은 WeaponActor에서 관리합니다. 일반 공격과 동일한 SceneGraph·발사체·충돌·사망 보상 경로를 사용합니다. 모니터 JSON의 `yokaiProgress`에 세 요괴의 레벨·경험치·필요 경험치·스킬 해금 여부·재사용 시간을 제공합니다.

자동 검증: 캐릭터와 독립 성장, 요괴별 성장 분리, 레벨 3 해금, 준비 전 무피해, 광역 스킬의 시민 보호, 재사용 제한, 전환 취소 및 재사용 유지, 산탄 5발, 클로 3회 타격. Release 빌드, 전체 smoke-test, 모니터 HTTP 통합 테스트를 통과했습니다. 진화 동행 외형과 세 스킬의 실제 렌더링 캡처를 생성했습니다.

현재 세션 내 성장입니다. R로 월드를 재시작하거나 게임을 종료하면 초기화되며 저장 기능은 포함하지 않습니다. 외형은 기존 2.5D 도형 렌더링을 확장했습니다.
