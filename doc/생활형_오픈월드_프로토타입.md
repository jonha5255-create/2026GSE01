# 잔명 마을 / 생활형 오픈월드 프로토타입

구현일: 2026-09-28

기준 문서: [이름 없는 도시 코딩용 명세서](이름_없는_도시_코딩용_게임_명세서.md).
원본 명세는 수정하지 않았다.

## 구현 범위

7개 맵 전체 캠페인이 아니라 명세 25절의 MAP_01 수직 슬라이스를 출발점으로,
사용자가 추가 요청한 NPC 생활 시뮬레이션을 우선 구현했다.
이 프로토타입은 **이동 → 조사 → 대화 → 계약 → 사냥/보급 → 외곽 원정 → 문지기 전투 → 기억 회수 → 요괴 강화 → 보고 → 자유 탐험**이 가능하다.

| 요청 | 구현 |
| --- | --- |
| 기존과 비슷한 맵 크기 | 청크 한 변 640, 주변 5×5=25청크 유지. 기존 무한 스트리밍/충돌/HDR/배칭 유지 |
| 마을과 NPC 거점 | 시작 지점 잔명 마을, 시장/구호소/기록소/집/학교 기록함/기억 제단 |
| NPC 목표 | 생존·재산·깨달음·약탈 성향, 체력 및 보유 자원에 따른 행동 결정 |
| PK와 약탈 | NPC↔NPC 전투, NPC→플레이어 공격, P 허용 후 F 인간 공격, 실제 재산 이전 |
| 직업별 활동과 거래 | 사냥꾼 3 / 약탈자 2 / 상인 2 / 구도자 2 / 경비 1 / 기록자 백연 1 |
| 계속 갱신되는 상태 | 프레임별 Actor 업데이트, 화면 밖/시작 청크 언로드/플레이어 사망 중에도 주민 생활 진행 |

외곽에 재생성되는 잔향귀 3체가 있으며 주민 수는 11명으로 고정한다.
각 주민은 SceneGraph가 소유하는 NpcActor다. 마을과 시설도 Actor로 구성했다.
화면에 보이지 않는 NPC를 삭제하거나 새로 생성해서 상태를 초기화하지 않는다.
단, 프로그램 종료 뒤까지 이어지는 세이브/오프라인 시뮬레이션은 아직 없다.

## 실행

Visual Studio에서 SimpleGame.sln → x64 / Release 빌드 후 실행한다.
빌드된 실행 파일은 저장소의 x64/Release/SimpleGame.exe다.

```powershell
.\x64\Release\SimpleGame.exe --seed=2026
```

기본 실행이 생활형 오픈월드다. 이전 파밍/보스 데모는 유지하며 다음 옵션으로 실행한다.

```powershell
.\x64\Release\SimpleGame.exe --level-one --seed=2026
```

## 조작과 권장 체험 순서

### 2026-10-02 요괴 형태 전환

- 1: 기본 검 요괴, 2: 원거리 요괴, 3: 빠른 클로 요괴.
- 숫자 키를 누르면 무기화 상태에서도 **선택한 요괴의 동행 상태**로 돌아온다.
  Q를 눌러 선택한 요괴를 무기화한다. 기본 시작 선택은 검이다.
- 무기화된 검: 기본 피해 24, 거리 85, 간격 0.5초.
- 무기화된 클로: 기본 피해 11, 거리 65, 간격 0.2초.
- 무기화된 원거리: 기존 성장형 영혼포 수치(레벨 1 피해 14, 거리 320, 간격 0.85초).
  몬스터 자동 사격과 클릭 지정 발사체 공격을 지원한다.
- 검/클로는 레벨과 무기 강화에 따른 피해 보정을 받는다. 동행 상태 클릭은 기존 기본 근접 공격이다.
- NPC 클릭 공격은 모든 형태에서 PK 허용이 필요하다. 원거리 PK 탄은 선택한 인간만 타격하고
  무관한 인간에게는 피해를 주지 않는다. 몬스터와 벽에는 기존 충돌 규칙을 적용한다.
- 교체해도 쿨타임은 유지한다. 이미 발사된 탄은 교체 후에도 날아가며 발사 당시 공격 권한을 유지한다.
- 세 요괴는 프로토타입 체험용으로 즉시 선택 가능하다. 스토리 계약 플래그나 동조율을 교체로 조작하지 않는다.

아래 초기 조작 설명의 Q 영혼포는 이제 **2 선택 → Q**에 해당하며,
무기화된 검/클로는 계약 전에도 사용할 수 있다. J/F는 선택한 형태로 공격하는 보조 단축키다.

| 입력 | 동작 |
| --- | --- |
| WASD | 화면 방향 기준 이동 |
| 마우스 왼쪽 클릭 | 클릭한 NPC/몬스터 근접 공격(거리 85 미만, 벽 너머 불가, 0.5초 쿨타임). 인간은 P로 PK 허용 필요 |
| E | 가까운 시설 조사/주민 대화, 구호소 치료·배상 |
| Q | 임시 영혼포 전환, 사거리/시야 안 잔향귀 자동 조준 |
| J | 묵 계약 후 근접 검격, 가장 가까운 잔향귀에 적용 |
| T / Y | 시장에서 잔향석 1개 판매 / 회복 재료 구입 |
| P / F | PK 허용 토글 / 가까운 인간 1명 공격 |
| TAB | 실시간 주민 목록 표시/숨김 |
| C | 기존 사거리 표시 |
| R | 시드 유지, 플레이어·주민·스토리를 새 세션으로 초기화 |
| H / B / N / M | 후처리 / 블룸 / 비네트 / 가장자리 흐림 |
| ESC | 종료 |

1. 시작 지점에서 오른쪽 아래에 있는 **서진의 집**으로 이동해 E를 누른다.
2. 시장으로 돌아온 뒤 왼쪽 아래 도로의 **학교 기록함**에서 학생증을 얻는다.
3. **백연의 기록소**에 학생증을 전달한다.
4. 학교보다 더 남쪽의 **묵의 기억** 제단에서 계약한다.
5. 외곽 도로에서 잔향귀 3체를 사냥한다. 2 선택 후 Q로 무기화하면 원거리 공격을 사용할 수 있다.
6. 백연의 기록소에서 E로 사냥 결과를 보고한다. 보상 20전.
7. 시장에서 T를 두 번 눌러 잔향석 2개를 실제 판매한다. 원정 보급 준비가 완료된다.
8. 마을에서 동쪽 도로를 따라 동부 중계기에 접근하고 E로 복구한다.
9. 더 동쪽의 승강장 신호 장치에서 E로 하린의 신호를 해독한다.
10. 존재하지 않는 역에서 E를 눌러 기록 장치를 조사한다. 문지기가 나타난다.
11. 요괴를 무기화하고 문지기를 제압한다. 원거리/근접 형태를 모두 사용할 수 있다.
12. 역의 기록 장치를 다시 E로 조사해 하린의 기억을 회수한다.
13. 마을의 기억 제단으로 돌아와 E로 묵을 각성시킨다. 강화 +1, 동조율 +20, 체력 회복.
14. 백연에게 최종 보고한다. 보상 80전/경험치 60. 이후 자유 탐험과 NPC 생활을 계속한다.

목표 패널에 다음 시설까지 거리와 화면 기준 방향을 표시한다.
시설 근처에서는 해당 위치에서 E를 누른다. NPC보다 가까운 시설을 우선 조사한다.
현재 퀘스트 시설이 상호작용 범위 안에 있으면 다른 시설보다 우선 선택한다.
PK 공격은 자동 사격과 분리했다. Q 발사체는 인간에게 맞지 않으므로 의도치 않은 PK가 없다.

2026-09-29: 대상을 왼쪽 클릭해 직접 공격할 수 있다. 클릭 1회당 공격 1회이며,
누르고 있기만 해서는 연속 공격하지 않는다. 묵 계약 전에도 몬스터에게 기본 공격(14)을 가하고,
계약 후에는 검격(24)으로 바뀐다. 기존 무기 강화 보정과 PK의 수배/약탈 규칙을 유지한다.
사거리 밖 대상에게 자동 이동하지 않으며 직접 가까이 다가가야 한다.
빈 공간 클릭은 피해를 주지 않지만, 무기화된 검/클로는 쿨타임을 소비하여 헛스윙 모션을 재생한다.
HUD 클릭은 공격하지 않는다. 기존 J/F 단축키와 Q 자동 사격은 유지한다.

## 시뮬레이션 규칙

### 목표 선택

각 주민은 약 0.8~1.08초 간격으로 목표를 재평가하고 이동·공격·회복은 매 프레임 처리한다.
생존 체력 기준은 최대 체력의 38% + survivalWeight×15%다.
생존 기준 아래에서는 휴식/구호소 복귀를 우선한다.
화면 밖에서도 동일한 규칙을 적용하며 길 찾기는 마을 로컬 좌표의 제한된 BFS를 사용한다.
이동 선분도 충돌 검사하므로 경로 점 사이에서 건물을 가로질러 가지 않는다.

일반 목표 비교:

- 약탈 점수 = raidWeight × wealthWeight × 1.7 × 체력 비율
- 사냥 점수 = wealthWeight × 0.8 + 빈곤 보정(12전 미만이면 +0.6)
- 명상 점수 = insightWeight × 1.2
- 전리품이 있으면 먼저 시장 판매를 시도한다.
- 상인·기록자·경비는 직업 전용 활동이 우선한다.

높은 약탈 성향은 부유한 인간을 목표로 선택하는 데 영향을 준다.
공격당한 주민은 반격하거나 체력이 낮으면 구호소로 물러난다.
경비는 약탈을 시작한 주민과 수배된 플레이어를 추적한다.
시작 중심 130m 이내는 NPC의 선제 약탈 대상에서 제외하지만 플레이어의 직접 PK는 가능하다.
이 구역이 전투 무적 구역은 아니므로 이미 시작된 반격이나 경비 대응은 계속된다.

### 경제

- NPC 사냥은 잔향귀의 12전과 잔향석 1개를 실제로 가져온다.
- 사냥꾼 등은 상인에게 잔향석을 8전에 판매한다.
- 피해를 입은 판매자는 상인의 재료를 12전에 구매해 소비하고 체력을 회복할 수 있다.
- 플레이어 판매는 8전, 회복 구매는 15전/체력 +40이다.
- 거래 상대의 소지금·재고가 부족하거나 회복할 필요가 없으면 거래하지 않는다.
- 인간 제압 시 피해자 소지금의 절반과 보유 잔향석 전량이 승자에게 이전된다.
- 사망한 대상에서 중복 보상을 얻을 수 없다.

화폐 공급원은 초기 자금과 잔향귀 재출현 보상이다.
회복 재료 소비와 수배 배상은 자원/화폐 소각이다.
거래·약탈 자체는 자원을 새로 생성하지 않는다.
현재는 가격 고정·단일 상품 경제이며 복잡한 생산/수요 모델은 후속 과제다.

### 성장과 회복

NPC는 전투 승리로 최대 체력이 성장하고, 구도자는 제단에서 명상하여 깨달음을 얻는다.
깨달음 5단계마다 최대 체력이 성장한다. 성장 횟수는 10으로 제한한다.
쓰러진 인간은 28초 후 원래 거점으로 돌아오며, 빼앗긴 재산은 복구되지 않는다.
잔향귀는 22초 후 체력과 정해진 사냥 보상을 회복한다.
이는 관찰 가능한 프로토타입을 유지하기 위한 부활 규칙이며 영구 사망은 아니다.

플레이어 PK는 수배를 올린다. P를 꺼도 수배·적대는 사라지지 않는다.
구호소 E에서 30전 배상으로 수배와 적대를 해제한다.
수배가 없을 때 구호소 E는 무료 치료다.
플레이어 사망 시 R로 새 세션을 시작할 수 있으며, 사망 화면에서도 NPC 시간은 흐른다.

## 스토리 적용과 명세 대비 차이

윤서진, 하린의 학생증, 기록자 백연, 기억관리국 언급, 묵 계약과 동조율을 반영했다.
집 → 학생증 → 백연 → 계약의 선행 조건을 검사하고 반복 조사로 보상을 중복 지급하지 않는다.
계약 후 잔향귀 사냥은 묵의 동조율을 올린다.

이번 버전은 전체 MAP_01 전투 명세를 완성한 버전은 아니다.
계약은 제단 대화로 단축했고, 검격은 기본 단일 공격이다.
기존 영혼포는 사냥 체험을 위한 임시 무기이며 소령 계약을 완료했다는 의미가 아니다.
골목의 추적자/망각귀/무명검객, 회피·패링·자세, 컷신,
MAP_02~07, 영구 융합, 엔딩, 세이브/로드는 미구현이다.
마을은 시작 지역 1개이고 새로운 청크마다 주민 집단을 무한 생성하지 않는다.
온라인 멀티플레이어 PK가 아니라 로컬 플레이어와 NPC 사이의 PK다.

## 코드 구조

| 파일 | 책임 |
| --- | --- |
| LivingWorld.h | 직업/행동/스토리 상태, NPC/시설 Actor, 시뮬레이션 인터페이스 |
| LivingWorld.cpp | 주민 생성, 목표 평가, 길 찾기, 전투, 자원 이전, 회복, 상태 로그 |
| LivingWorldInteraction.cpp | 플레이어 상호작용, 거래, PK, 명세 기반 조사·계약 진행 |
| LivingWorldView.cpp | NPC/시설 렌더링, 지도, 주민 목록, 한국어 UI |
| LivingWorldTests.cpp | 경제·목표·PK·계약·장기 시뮬레이션 회귀 검사 |
| LevelOne / GameplayContext | SceneGraph 업데이트에 생활 시뮬레이션 서비스 연결 |
| PrototypeWorld | 기존 스트리밍/충돌과 통합, 입력 라우팅, 실제 맵 테스트 |
| WeaponActor / ProjectileActor | 잔향귀 조준과 명중, 인간 자동 사격 제외 |

World 시스템은 Actor ID만 보유하며 배치 객체 소유권은 SceneGraph에 둔다.
마을 자식 로컬 좌표와 경로를 사용하므로 원점 재배치 시 주민 위치가 중복 이동하지 않는다.
렌더링은 기존 배칭/파일 메시 캐시를 사용하며 NPC마다 GL draw를 추가하지 않는다.

## 지속 로그 및 검증

실행 파일 옆 Logs/render-*.jsonl에 다음 이벤트를 추가했다.

- world_start: 주민 시뮬레이션 초기화
- npc_decision: ID/이름/선택 행동/약탈 성향/체력/자산
- npc_trade, player_trade: 실제 거래
- hunt, raid, player_defeat: 사냥/제압/재산 이전

### 2026-10-02 근접 공격 애니메이션 및 도시형 맵

마을의 주요 동선과 시설 접근성을 유지하며 미니맵도 실제 필지/도로를 표시한다.
실제 지도 데이터나 곡선 도로를 구현한 것은 아니며, 직교 도로 기반 도시형 프로토타입이다.

### 2026-10-06 플레이어 중심 지도 및 원정 확장

기존 지도는 시작 청크의 고정 배치를 사용하고 플레이어 아이콘만 가장자리에 제한했다.
이를 스트리밍된 ChunkActor의 플레이어 상대 좌표를 사용하는 주변 지도로 변경했다.
플레이어는 항상 중앙에 있고 도로/건물/주변 NPC/시설은 이동에 따라 연속 갱신된다.
멀리 있는 현재 목표는 지도 경계의 금색 표시로 안내한다. 시작 마을을 언로드해도 지도를 사용할 수 있다.
지도 도형은 UI 영역에 CPU 클리핑하여 기존 배칭에 포함하며 별도의 지도 drawcall을 추가하지 않는다.
고정 townLayout 캐시는 제거했다. 절대 청크 좌표를 float로 변환하지 않고 기존 상대 좌표를 재사용한다.

기존 5단계 도입부 뒤에 보고/실제 거래/외곽 조사/문지기/회수/각성/최종 보고를 연결하여 14단계로 확장했다.
동쪽 원정 거점은 마을 로컬 좌표 (1190,0), (1830,0), (2470,0)에 두며 연결된 간선도로 위에 배치한다.
문지기는 역 조사 시 한 번 생성되는 NpcActor이며 체력 240, 근접 피해 12, 공격 간격 1.2초다.
플레이어를 근처에서 추적하고 원래 위치로 복귀하며 건물 충돌을 따른다. 플레이어가 문지기를 제압해야 퀘스트가 진행된다.
재출현하는 마을 잔향귀와 달리 문지기는 제압 후 재생성하지 않는다.
NPC 자동 거래는 보급 목표에 포함하지 않고 보고 이후 플레이어의 실제 잔향석 판매 2회만 집계한다.
보상/문지기 생성/각성은 반복 상호작용으로 중복 실행되지 않는다.

이 확장은 기존 조사 프로토타입의 플레이 가능한 원정 에피소드이며 원본 명세의 7개 맵 캠페인 구현 완료를 의미하지 않는다.
세이브와 전체 캠페인/숨겨진 퀘스트 생성/영구 융합은 후속 범위다.
