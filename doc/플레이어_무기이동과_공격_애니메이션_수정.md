# 플레이어 무기 이동·공격 애니메이션 수정

검증일: 2026-11-04. 실제 게임의 검·원거리·클로 플레이어를 대상으로 수정했습니다.

## 확인한 원인

- 무기 상태에서는 이동 중에도 마지막 `weapon.aim`을 몸 방향으로 사용했습니다. 옆이나 뒤를 보며 앞으로 달리는 형태가 발생했습니다.
- 무기를 장착한 상태에 일반 보행의 팔 흔들림을 그대로 적용했습니다. 손에 붙은 무기도 함께 크게 흔들렸습니다.
- 사격 이동 정지용 `firingHold=0.16초`를 애니메이션 재생 시계로 사용했습니다. 0.8초짜리 쌍권총 4연사 클립 전체가 이 시간 안에 압축됐고, 정지가 풀리면 동작도 바로 끊겼습니다.
- 걷기·대기·공격을 교체할 때 자세 보간이 없었습니다. 클로의 재공격이나 무기 전환에서도 팔과 몸이 갑자기 다른 자세로 바뀔 수 있었습니다.

## 변경한 동작

`PlayerActor`에서 이동 방향, 보행 시계, 이동 혼합 비율을 관리합니다. 공격하지 않을 때는 이동 방향을 바라보고, 정지하면 마지막 방향을 유지합니다. 공격 중에는 공격 시작 시의 조준 방향을 사용하고 회전은 시간에 따라 부드럽게 보간합니다.

새 `PlayerAnimator`가 대기와 달리기 동작을 혼합합니다. 무기를 들면 spine 하위의 상체에 해당 무기의 준비 자세를 적용하고, 하체는 보행을 유지합니다. 이동 중 공격도 하체 보행과 상체 공격을 함께 재생하며, 정지 공격은 전신 동작을 사용할 수 있습니다.

뼈대의 로컬 위치·스케일과 quaternion 회전을 먼저 혼합한 뒤 부모 계층을 계산합니다. 완성된 스킨 행렬을 단순 보간하지 않으므로 전환 중 관절이 축소되는 현상을 방지합니다. 상태 전환은 약 0.08초, 공격 진입·복귀에도 별도 혼합을 적용합니다.

| 무기 | 시각적 재생 시간 | 원본 클립 사용 |
| --- | ---: | --- |
| 검 | 0.50초 | 준비 → 베기 → 복귀 |
| 원거리 | 0.20초 | 첫 발사 이벤트부터 다음 발사 이전까지 한 번의 반동 구간 |
| 클로 | 0.24초 | 원본의 두 타격 구간을 좌우 공격에 나눠 사용 |

무기의 시각적 공격 시계를 이동 정지·쿨타임과 독립시켰습니다. 사격 정지가 끝난 뒤에도 짧은 복귀 동작을 마칠 수 있습니다. 요괴 선택이나 Q 전환 시에는 이전 시각적 공격을 취소합니다. 피해 판정과 발사체 생성은 기존 전투 로직이 담당합니다.

## 성능 처리

불변 GPU 메시와 기존 GPU 스키닝을 재사용합니다. 혼합 중간 단계에서는 로컬 변환만 계산하고, 최종 자세에서 골격 행렬을 한 번 계산합니다. 본 이름·부모 정보는 불변 모델에 두고 자세에는 변환 값만 저장합니다. 대기·이동 비율이 0이나 1인 경우 불필요한 혼합도 생략합니다.

Release 시작 월드의 기본 60FPS 제한 실행을 재측정했습니다. seed=2026, 1280×800, 모니터 서버 끔, 600프레임 중 첫 30프레임 제외 기준으로 60.00FPS, 프레임 p95 17.04ms, 평균 RenderCPU 1.69ms였습니다. 플레이어 자세 계산을 포함한 평균 ArtPose는 0.10ms였습니다. 원시 로그와 요약은 이 문서의 validation 폴더에 보관합니다.

같은 날 수정 전 커밋 `2ee9d1e`도 별도 폴더에 Debug 빌드해 순차 비교했습니다. 같은 seed와 180프레임, 첫 30프레임 제외 기준으로 수정 전 21.60FPS, 수정 후 22.08FPS였습니다. 단일 실행 비교이며 과거 다른 날의 Debug 측정값과 직접 비교하지 않습니다. [전후 요약](validation/player-motion/performance-summary.json).

확대 동작 검증은 3무기 × 120프레임이며, 첫 메시 업로드 이후 추가 GPU 메시 업로드가 0회인지 검사합니다.

## 검증 및 확인 방법

- 기존 게임·장면·렌더러 검사: 234 PASS / 0 FAIL.
- x64·x86의 Debug·Release 네 가지 빌드 구성 통과.
- 실제 GLB를 사용해 무기 이동 방향, 준비 상체·달리기 하체, 한 발당 반동 구간, 공격 방향 고정, 중단된 공격의 자세 연속성, 무기 해제, 30/120FPS 회전 결과를 검사했습니다.
- 동일 시각에 두 번 렌더링해도 애니메이션 시계가 진행되지 않는지 검사했습니다.
- 82개 GLB 로딩·스키닝·클립 검증과 검/총/클로 확대 렌더 검사를 통과했습니다.

```powershell
./x64/Release/SimpleGame.exe --asset-test
./x64/Release/SimpleGame.exe --smoke-test --seed=2026 --no-monitor
./x64/Release/SimpleGame.exe --player-motion-test --no-monitor
```

마지막 명령은 실행 파일 옆에 `player-motion-{무기번호}-{프레임}.bmp`를 저장하고 종료합니다. 무기번호는 검 0, 원거리 1, 클로 2입니다. 대기 → 이동·공격 → 방향 전환 → 정지를 확대해서 확인할 수 있습니다.
